What it is

A private alternative to Seedr — without the limits.

Hosted torrent services cap your speed, cap your storage, queue your downloads and charge you monthly. Lumaseed is the same idea running on hardware you already own, so none of those limits exist.

No throttling, anywhere

Nothing in Lumaseed slows a transfer down. It opens far more peer connections than a default client and saturates whatever your line can carry.

Files of any size

10 GB, 50 GB, a whole season — there is no cap, only your disk. Finished torrents come back as individual files or one zip of the entire folder.

Nothing leaves your network

No account, no third-party storage, no logs on someone else's server. The files never touch infrastructure you don't control.

Built in

Tuned for throughput, honest about numbers.

The engine is configured for maximum speed out of the box, and every figure the interface shows is computed from bytes actually verified on disk.

One command to run

docker compose up -d and you have a working client. No Node.js, no build step, no configuration file to learn.

Magnet links or .torrent files

Paste a link or drag a file onto the drop zone. Both start immediately, and torrents resume from disk if the server restarts.

Download the whole folder

Finished torrents stream back as a single zip with the folder structure intact — built without compression, so it moves at disk speed.

Byte-accurate progress

Progress, speed and ETA come from the verified piece bitfield, weighted by file size. What the bar says is what is on your disk.

Finds rare peers

DHT, PEX, local discovery and thirteen public trackers stay connected the whole time, so a sparse torrent starts the moment someone appears.

Light and dark

A clean interface that follows your system theme, works on a phone, and needs no internet access to render — fonts and icons are bundled.

Free, open source, and yours to run.

Clone it, read every line, change what you like. MIT licensed, no telemetry, no account, no upsell.
